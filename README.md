# 自动技能循环脚本

基于 AHK (AutoHotkey) 编写的游戏技能自动循环脚本，通过像素颜色检测实现技能的自动释放。

## 功能特性

- **多职业配置**：支持创建和管理多个职业配置文件
- **技能循环**：根据预设的技能顺序自动释放技能
- **颜色检测**：通过像素颜色判断技能 CD 状态，智能释放技能
- **两种启动模式**：按住启动 / 触发启动
- **全屏取色**：冻结屏幕进行精确取色，支持多点取色
- **热键自定义**：可自定义启动和取色热键

## 文件结构

```
start_config/
├── config.ini          # 全局配置（热键、当前职业、启动模式）
├── 职业1.ini           # 职业配置文件
├── 职业2.ini
└── ...
```

## 配置文件说明

### config.ini（全局配置）

```ini
[当前职业]
职业名称=战士

[技能按键]
startkey=Capslock
getkey=F9

[启动模式]
模式=按住启动
```

### 职业配置文件（如：战士.ini）

```ini
[主循环]
循环顺序=技能1，技能2，技能3

[技能信息]
技能1=1,500
技能1x=100
技能1y=200
技能1color=FF0000

技能2=2,300
技能2x=150
技能2y=250
技能2color=00FF00
```

**字段说明：**
- `循环顺序`：技能释放顺序，用中文逗号 `，` 分隔
- `技能按键=热键,延迟`：技能的触发按键和延迟时间(ms)
- `技能x/y`：技能图标的屏幕坐标
- `技能color`：技能可用时的颜色值

## 使用方法

### 1. 启动脚本

双击运行 `自由循环开源.ahk`

### 2. 快捷键

| 快捷键 | 功能 |
|--------|------|
| `Capslock`（默认） | 启动/停止技能循环 |
| `F9`（默认） | 打开取色界面 |
| `F10` | 打开设置界面 |

### 3. 添加新职业

1. 按 `F10` 打开设置界面
2. 点击「新建」按钮
3. 输入职业名称
4. 在职业配置文件中编辑技能信息

### 4. 配置技能

1. 按 `F9` 打开技能列表
2. 选择要配置的技能
3. 点击「取色」按钮
4. 移动鼠标到技能图标位置，按 `右键` 确认
5. 返回列表，输入技能热键和延迟

### 5. 启动模式

- **按住启动**：按住热键时循环，松开停止
- **触发启动**：按一次启动，再按一次停止

## 取色说明

### 单点取色
- 技能只有一个判断条件时，直接检测该点颜色

### 多点取色
- 技能有多个判断条件时（用 `=` 连接），需所有点颜色匹配才释放
- 例如：`技能1=技能2` 表示同时检测两个技能的状态

## 依赖

- [AutoHotkey v1.1+](https://www.autohotkey.com/)
- [Gdip_All.ahk](https://github.com/buliasz/AHKv2-Gdip) - GDI+ 图形库

## 注意事项

1. 技能分隔符必须使用**中文逗号** `，`
2. 颜色值为 16 进制 RGB 格式（如 `FF0000`）
3. 延迟时间单位为毫秒 (ms)
4. 取色时按 `ESC` 可取消当前操作
